# v0.1.2 release verification

[GitHub run 44865848547](https://github.com/rmuxapp/rmux/actions/runs/44865848547)
completed successfully: native macOS, Windows and Linux builds, packaging,
macOS signing/notarization, publication, and Sparkle feed update.

[Release](https://github.com/rmuxapp/rmux/releases/tag/v0.1.2) contains the macOS
DMG and ZIP, Linux tar.gz, Windows ZIP, appcast.xml and SHA256SUMS.

Downloaded artifacts were inspected directly:

- macOS ZIP: CFBundleIconFile points to rmux.icns, its bytes match the checked-in
  icon, bundle version is 0.1.2, and SUFeedURL uses rmuxapp/rmux.
- Windows ZIP: rmux.exe PE resources contain icon group ID 1 with 16, 32, 128 and
  256 pixel images. GPUI loads resource ID 1 for its window icon.
- Linux tar.gz: SVG bytes match the checked-in mark, desktop entry names that
  icon, and the rmux executable retains executable permissions.

The old owner's raw Sparkle-feed URL still returned HTTP 200 after transfer.
Native desktop icon rendering on Linux/Windows and end-to-end Sparkle installation
remain unverified; artifact checks do not replace those runtime checks.
The pane-zoom toolbar change on main landed after the release commit and is not
included in v0.1.2.
