- `codesign --verify --deep --strict`, `xcrun stapler validate`, and
  `spctl --assess --type execute` all passed on the downloaded bundle.

  observed in the locally packaged build with the same app source. Toolbar icons
  are visible in the real screenshot committed with the README.
- The final downloaded-app update-dialog check was blocked by a locked Mac.
  An actual version-to-version download/install/relaunch remains to be tested
  when preparing the next update. This report does not claim complete cmux parity.

The first CI attempt passed Apple notarization but stalled in generate_appcast.
The successful pipeline uses a temporary private-key file for Sparkle, avoiding
interactive Keychain access on a headless runner. Its compiled dependencies are
cached before signing. Private keys never enter the repository or release assets.
