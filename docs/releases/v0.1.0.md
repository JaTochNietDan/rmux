# rmux 0.1.0 — first preview

A native terminal workspace built in Rust, powered by Ghostty and GPUI.

- Named workspaces, groups, tabs, nested splits, and multiple windows.
- Keyboard navigation, searchable command palette, and configurable shortcuts.
- Terminal selection, search, scrollback, shell integration, and session recovery.
- Appearance settings, Git branch context, in-app notifications, and task status.
- Optional local automation socket and bundled `rmuxctl` client.
- Sparkle updates from the macOS app menu.

Download `rmux-0.1.0-macos-arm64.zip`, unzip it, and move rmux.app to Applications.
The app is signed with Developer ID and notarized by Apple. SHA256SUMS provides
the archive checksum. Third-party notices are included inside the app bundle.

This is an early preview for Apple Silicon Macs. Browser surfaces, remote
workflows, native OS notifications, and full cmux parity remain in development.
Linux and Windows binaries are not included. There is no promise of zero lag or
a fixed memory ceiling; measured performance depends on the workload.
