# rmux 0.1.1 — preview

This preview adds downloadable packages for all three desktop platform families,
built on native GitHub Actions runners:

- **macOS Apple Silicon:** signed and notarized DMG with drag-to-Applications installation; signed ZIP retained for Sparkle updates.
- **Linux x86-64:** portable tar.gz built on Ubuntu 24.04, with `rmux` and `rmuxctl`. Requires compatible system libraries, X11/Wayland and a working graphics driver.
- **Windows x86-64:** portable ZIP with `rmux.exe`, `rmuxctl.exe` and Ghostty's runtime DLL. Extract all files together. This package is unsigned.

The terminal workspace includes ongoing improvements to layouts, configuration,
file previews, shell integration and memory diagnostics. The experimental embedded
browser remains opt-in for source builds and is not enabled in these packages.

Linux and Windows are early previews: native UI, IME, graphics, lifecycle and
performance acceptance remain incomplete. This release does not claim cmux parity
or a zero-lag guarantee. Automatic updates currently apply to macOS only.

Use `SHA256SUMS` to verify downloads. Report issues with your OS version and graphics
hardware at https://github.com/JaTochNietDan/rmux/issues.
