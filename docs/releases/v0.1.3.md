# rmux 0.1.3 — preview

Fixes missing macOS Dock and Cmd+Tab icons by explicitly setting the running
application's icon at startup. The icon is embedded in the executable, so it is
available for both app-bundle and direct binary launches.

Also adds a pane-toolbar zoom button with the configured shortcut in its tooltip.
New-tab and split toolbar controls now ignore non-primary mouse clicks.

Packages remain signed/notarized on macOS Apple Silicon, portable on Linux x86-64,
and unsigned on Windows x86-64. macOS users can update through
**rmux → Check for Updates…**. Linux and Windows update manually.
