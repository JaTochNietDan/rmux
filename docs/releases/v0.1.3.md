# rmux 0.1.3 — preview

This release improves everyday navigation and the command palette.

- Cmd+P opens the command palette on macOS. Search has a padded field, full-width selection, aligned shortcuts and everyday commands first.
- Cmd+[ / ] cycles split panes; Cmd+Shift+[ / ] switches tabs. Shifted bracket events on macOS are now handled correctly.
- Pane zoom has a toolbar button. Tab context menus include New Tab and clearer sections.
- Finished SSH terminals offer Reconnect SSH or a local shell. Restored SSH tabs show that they are disconnected and offer an explicit connection action.
- rmux is now MIT licensed. Release packages include the license and third-party notices.

Packages: signed/notarized macOS Apple Silicon DMG and Sparkle ZIP, Linux x86-64 tar.gz, and unsigned Windows x86-64 ZIP. Linux requires Ubuntu 24.04-compatible libraries. Linux/Windows native UI and cross-platform performance acceptance remain in progress. The experimental browser is not enabled in these builds.

Use **rmux → Check for Updates…** on macOS. Other platforms update manually.
