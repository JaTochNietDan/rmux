# rmux 0.1.2 — preview

This release adds the rmux icon across desktop packages:

- macOS: a multi-resolution icon in the signed app bundle.
- Windows: an embedded executable icon, also used by GPUI windows.
- Linux: an SVG launcher icon, matching window application ID, and optional desktop setup instructions.

Release builds now refresh compilation caches across source revisions. The user
guide includes mise installation instructions for our prerelease channel.

Packages: signed/notarized macOS Apple Silicon DMG and Sparkle ZIP, Linux x86-64
tar.gz, and unsigned Windows x86-64 ZIP. Linux requires Ubuntu 24.04-compatible
libraries. Linux/Windows native UI and cross-platform performance acceptance
remain in progress. The experimental browser is not enabled in these builds.

See SHA256SUMS for download checksums. macOS installations can use
**rmux → Check for Updates…**; other platforms update manually.
