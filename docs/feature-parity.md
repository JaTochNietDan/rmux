# cmux feature parity inventory

Target: macOS, Linux and Windows. Current status is tracked in [features.json](reference/features.json): 37 families are **in progress**, with explicit implementation sources and remaining gaps; 95 are **not started**. No family is verified or released. Phases are proposed sequencing, not exclusions. The inventory captures product capabilities and candidate contracts at the pinned upstream revision, not proof that every capability ships in the latest stable binary.

Upstream snapshot: [`a76816e4f078`](https://github.com/manaflow-ai/cmux/tree/a76816e4f0788003758b9434ab702068a640fb5d), reviewed November 19, 2026.

## Evidence and scope

- **D**: documented behavior in the pinned repository; exact release availability still needs a runtime check.
- **I**: command, schema or capability declaration found; detailed behavior requires implementation/runtime verification.
- **B**: explicitly beta, early access, preview or nightly in the cited material.
- **U**: explicitly listed under Unreleased in the changelog.
- **P**: proposal/RFC; not included in implemented parity until validated.

Acceptance criteria below are rmux requirements proposed from those capabilities, not claims about cmux test coverage. Platform exceptions and unresolved backend choices are in [architecture](architecture.md). Each row is a feature family; the JSON inventories preserve finer command/configuration granularity.

## Removed features are not current parity obligations

The changelog removes the agent turn rail and previous/next agent-turn shortcuts in 0.65.2, and also removes the terminal Jump to Bottom button. Do not recreate those solely because an older release introduced them. Prompt navigation elsewhere must be checked separately. [Changelog](https://github.com/manaflow-ai/cmux/blob/a76816e4f0788003758b9434ab702068a640fb5d/CHANGELOG.md)

## Completion rule

A row becomes verified only after linked acceptance evidence passes on each supported platform, or a platform-specific exception is explicitly recorded. Unsupported platforms remain gaps; deferring a feature does not count as parity. Full ecosystem parity additionally includes P7, while proposals remain a separate watchlist.
